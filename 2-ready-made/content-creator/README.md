## Where things live
| Folder | What goes in it |
|---|---|
| `brand/` | How the content looks and sounds: colours, fonts, logo files, voice and tone, do's and don'ts. |
| `content/` | Everything written before filming: ideas, series, scripts, the posting schedule (`SCHEDULE.md`). |
| `content/ideas/` | The idea inbox (`INBOX.md`). One line per idea; an idea becomes a script when you pick it. |
| `content/scripts/` | One file per episode: `E001.md`, `E002.md`… (the episode code is used everywhere). |
| `content/series/` | Recurring formats and series: what each one is, its rules, its length, its posting days. One file per series. |
| `editor/` | What the editor (you, or an AI editor) uses: templates, graphics, sounds, presets. Fixed files, so every edit looks the same. |
| `editor/kit/` | Reusable pieces: graphics, sound effects, lower thirds, intros, music beds. Name them by what they are, not `final2.mov`. |
| `editor/templates/` | Layout and caption templates: one file per template, with when to use it and its settings. |
| `exports/` | Approved final videos only: `E001_<short-title>.mp4`. If it's here, it's ready to post. |
| `footage/` | Raw material. **Read-only once it's in:** never edit, rename or delete originals. |
| `footage/01_raw/` | Camera files, one folder per episode: `01_raw/E001/`. |
| `footage/02_audio/` | Separate audio: mic recordings, voice-overs, music you have the rights to use. |
| `footage/03_screen/` | Screen recordings and screenshots for inserts, per episode: `03_screen/E001/`. |
| `work/` | Edits in progress, one folder per episode: `work/E001/` (project file, drafts, notes, a short `REPORT.md`). |
| `_system/` | The AI's memory and rules for this project. You rarely need to open this folder: the AI reads and updates it. |
