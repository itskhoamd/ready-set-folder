## 8. Rules for this project
1. **New things land in `inbox/`.** The AI sorts the inbox when the human says "tidy up" (at least once a week).
2. **Work in progress lives in `work/`.** Make a sub-folder per topic once there are more than ~10 files; give it a `README.md`.
3. **Finished things go to `output/`**, named `YYYY-MM-DD_<what>`. Never edit a finished file: copy it back to `work/` to change it.
4. **`reference/` is read-only:** briefs, research, examples, manuals. Note where each came from.
5. **When the project grows a clear shape** (clients, episodes, workflows…), ask the human whether to switch to a matching blueprint ("redo setup").
