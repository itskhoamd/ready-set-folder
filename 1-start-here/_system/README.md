# _system/

The AI's memory and rules for this project. You rarely need to open this folder: the AI reads and updates it.

| File / folder | What it is |
|---|---|
| `HOUSE-RULES.md` | How work is done here. Change a rule with a decision in `DECISIONS.md` first. |
| `HANDOFF.md` | Where the last session stopped and what's next. Rewritten at every "wrap up". |
| `CHANGELOG.md` | Every change, dated, newest on top. |
| `DECISIONS.md` | Every decision and why. Never edited, only replaced. |
| `JOURNEY.md` | Optional story log (useful if you build in public). |
| `SETUP.md` | The first-run setup the AI follows (questions → plan → build). |
| `PROJECT-CARD.md` | The template for your `README.md`. |
| `GUIDE-TEMPLATE.md` | The format for step-by-step guides. |
| `blueprints/` | Folder plans for different kinds of projects (used by the setup). |
| `_archive/` | Old versions of docs. |
| `_to_delete/` | The trash: the AI moves files here instead of deleting. **You empty it.** |
