## 8. Rules for production work
1. **One folder per job**, copied from `jobs/_JOB-TEMPLATE/`, named `YYYY-MM_<client>_<project>`.
2. **Originals in `00_brief/` are never edited.** Work on copies elsewhere.
3. **Every spend goes into `petty-cash.csv` the same day**, with a photo of the receipt in `receipts/` named `YYYY-MM-DD_<item>_<amount>.jpg`.
4. **Schedule changes:** update the timeline, add a timed line to the job's `CHANGELOG.md`, and send changes to crew only after the human's OK.
5. **People's personal data stays in `04_crew-cast/`.** It never goes into the portfolio, summaries, chats with other tools, or any shared copy.
6. **At wrap, the AI writes the wrap report** in `05_wrap/` and **one portfolio paragraph** (role, project type, what you did, one number), added to `portfolio/PORTFOLIO.md` after the human checks it.
7. **Check the NDA before posting anything** (BTS photos, client names, footage).
